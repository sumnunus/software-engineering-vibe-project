### 배포 중 발견된 문제와 조치

Vercel 서버리스 함수에서 catch-all 경로 파라미터가 비어 들어와 API 엔드포인트를 읽지 못하는 문제가 있었다. 요청 URL의 pathname에서도 엔드포인트를 복원하도록 서버 함수를 수정한 뒤 Production에 재배포하였고, 정류장 검색 및 도착 정보 조회가 정상 동작함을 확인하였다.

## 결론

ReadyGo의 주요 기능은 로컬 환경과 Vercel Production 배포 환경에서 정상 동작하는 것으로 확인되었다. 준비물 관리, 날씨 및 옷차림 추천, 버스 도착 정보, 외출 시각 계산 기능은 요구사항과 연결하여 검증되었으며, 발견된 주요 UI/연동/배포 결함은 수정 후 재검증되었다. 다음 단계에서는 이 테스트 결과를 바탕으로 lessons learned와 최종 보고서를 정리한다.
